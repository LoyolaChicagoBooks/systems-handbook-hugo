##############
 Getting Help
##############

This page describes how to get help.

*******
 Email
*******

Please direct all inquiries, including requests for any department
service, to Miao Ye (helpdesk@cs.luc.edu). There are no separate
addresses for individual services. Use the same address for:

-  password resets and account problems (see :doc:`User Accounts
   </department_services/user_accounts>`)

-  virtual machine requests (see :doc:`Virtualization
   </department_services/virtualization>`)

-  software requests for the Windows labs (see :doc:`Windows Labs
   </its_services/windows_labs>`)

-  Google Site requests (see :doc:`Google Apps
   </department_services/google_apps>`)

-  access to the JupyterHub server (see :doc:`Secure Shell
   </how_to/secure_shell>`)

*****************
 Microsoft Teams
*****************

Please join the Loyola CS Systems group on Loyola’s Microsoft Teams
effective after January 1, 2022. This is available to Loyola faculty,
staff, and students only.
